# Uso de Inteligencia Artificial

En este proyecto se ha utilizado IA como apoyo en algunas partes del desarrollo.

Principalmente se ha usado para:

- Ayudar con la visualización de la trayectoria en RViz.
- Crear y configurar el nodo del rastro del robot.
- Ayudar con el fichero launch.
- Organizar y corregir algunas partes del código.

Todo lo generado con ayuda de IA se ha probado y adaptado al funcionamiento de la práctica.
